# 模板技能

调用此工具**仅是加载解题规范文本**，不会触发任何外部计算，也不会自动为你生成答案。调用成功后，你需要**立即**基于加载的规范开始输出你的思考过程（`thought`），而不是等待返回结果或保持沉默。


## 执行流程强制顺序

### 1. 三段式强制结构

每次调用工具必须遵循：**Thought → [可选：代码验证] → Thought → 下一次工具**

-**绝对禁止**：连续两个 `tool_calls` 之间没有非空 `thought`

-**绝对禁止**：`thought` 为空时直接调用 `run_shell` 或 `submit_answer`

### 2. Thought 内容红线检查

`thought` 必须包含以下要素，**缺少任意一项即视为空**：

- [ ] 当前正在处理第几问（如"现在处理第(3)问"）
- [ ] 当前步骤的代数变形（如"令 $f(x) = 5\cos x - \cos 5x$，求导得..."）
- [ ] 下一步计划（如"接下来解方程 $f'(x) = 0$"）

### 3. 数值计算熔断机制

当代码中出现以下模式时，**立即中断执行**，强制要求先在 thought 中写出解析推导：

```python


np.linspace(...,10000)# 网格搜索


np.max(...)# 数值取极值


for ... inrange(...):# 暴力枚举


scipy.optimize            # 任何优化库
```


## Thought 非空检查

-**禁止**连续两次调用工具之间 `thought` 为空

- 每次 tool_calls 后必须立即输出自然语言分析，说明：
- 上一步得到了什么结果
- 下一步要做什么代数变形

-**违规处理**：若 thought 为空，强制要求"请先用中文写出当前推导步骤"

## 解题步骤

1. 阅读题目，将题目拆分为条件与所求两部分，对于求解类题目，要求的数值即为所求；对于证明类题目，证明的结论即为所求，记住题目一共有多少个小问；
2. 一步一步对条件进行变形和组合，推出所求；
3. 将你的思考过程转换为人类的自然语言并调用 submit_answer输出，输出必须包含自然语言阐述的思考过程。
4. 检查是否完全作答所有小问。
5. 如果运行step超过13，仍然无法求出答案，请将你能联想到的任何对条件的变形组合、推导出的有效结论全部以自然语言输出到submit_answer中，这样可以得到过程分。如果你对答案有猜想，但不能写出完整的过程，也请你在输出完可能的过程后，在最后输出“因此答案为”，再输出你猜想的答案。

## 注意

对于非选择填空题，你必须详细地写出你对于题目的解答过程，必须包括你从题目所给的条件一步步递推到所求的结论的全过程。同理，如果题目为证明题，你也必须详细写出从题目条件递推到所证明结论的全过程。

对于每一步运算，你必须逐步列出过程，不允许跳过任何步骤，且每一次运算后，必须进行检查。当得出最终结论后，你需要重新进行一次检查，将你所求的结果代入回题目中，验证是否符合题目的条件。

调用 submit_answer 时，参数 `answer`**必须**包含以下全部内容：

1.**分问标识**：明确写出 "（1）"、"（2）"

2.**推导过程**：从已知条件到结论的完整代数变形

3.**最终答案**

禁止：

- submit_answer中只提交 `\frac{7-(3m+7)(-2)^m}{9}` 这样的孤立公式
- 提交 "见上述过程"、"答案为..." 等不完整表述

## 计算策略

### 1. 解析解优先原则

-**默认必须求解析解**（含根式、分式、参数的精确表达式）

-**绝对禁止**以下行为：

- 用 `for i in range(100000)` 网格搜索找极值点
- 用二分法/牛顿迭代逼近根，然后试图反推解析式

-**允许例外**：仅当题目明确要求"近似值"、"保留几位小数"时，才在解析解后附加数值结果

当你的运算中出现了强制求数值解的过程时，必须立刻停止，重新尝试使用解析的方法进行处理。

### 2. 代数推导可视化要求

**禁止黑盒**：不允许直接输出 Python 计算结果作为答案，必须展示：

代换过程（如"令 $t=\tan\frac{\theta}{2}$"）

多项式展开、因式分解步骤

## 示例：

你写在 `submit_answer`中的解答应类似如下格式：

若 {b_n} 为等差数列，则 2b_2 = b_1 + b_3，即 2×(2×3)/(a_1+d) = (1×2)/a_1 + (3×4)/(a_1+2d)，即

a_1^2 - 3a_1d + 2d^2 = 0，所以 a_1 = d 或 a_1 = 2d，当 a_1 = d 时，a_n = nd，故 S_n = n(n+1)d/2，

T_n = n(n+3)/(2d)，又 S_99 - T_99 = 99，即 (99×100d)/2 - (99×102)/(2d) = 99，即

50d^2 - d - 51 = 0，所以 d = 1/5 或 d = 1（舍）；

即 a_1 = 2d 时，a_n = (n+1)d，b_n = n/d，故 S_n = n(n+3)d/2，T_n = n(n+1)/(2d)，又 S_99 - T_99 = 99，

即 (99×102d)/2 - (99×100)/(2d) = 99，即 50d^2 - d - 50 = 0，所以 d = -51/50（舍）或 d = 1（舍）；

综上：d = 51/50。

## 提交前强制检查

调用 `submit_answer` 前必须完成以下自检，**全部通过**才能提交：

### 1. 小问完整性检查

- [ ] 题目中若有 (1)(2)(3)... 标记，答案中必须一一对应
- [ ] 确认没有遗漏任何小问（特别是 (i)(ii) 这类子问题）

### 2. 推导完整性检查

- [ ] 每个"设..."必须有对应的"解得..."或"故..."
- [ ] 括号、方框、分式必须闭合匹配

### 3. 字符串完整性验证

- [ ] 答案字符串不得以 "("、"["、"{"、"设"、"因为"、"即" 等开头性词汇结尾
- [ ] 检查最后一个字符：如果是运算符（+ - * / =）或未完成的分式，**禁止提交**

若自检发现漏答或截断，必须：

1. 继续推导完成剩余部分
2. 合并完整答案后再次提交
3. **绝对禁止**提交半成品（如未闭合的括号、未解完的方程）
